# Mi primer repo

Repositorio de práctica de Javier Levano para aprender el flujo de Pull Requests.

## Sobre este repositorio

Este repositorio se usa para practicar el flujo completo de contribución en GitHub:
crear una rama, hacer un cambio, subirlo y abrir un Pull Request.

## Proyectos

- [`sunat_facturas/`](sunat_facturas/README.md): descarga de facturas de compras y ventas desde SUNAT (API SIRE) a Excel.
